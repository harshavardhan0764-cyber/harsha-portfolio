## ⚡ Interactive Features

- **Floating Glass Navbar**:
  - Dynamic ScrollSpy color-switching: dark text over the light hero section, glowing slate & white over the obsidian sections.
  - Quick download trigger for resume and APK.
  - Sound effects toggle and responsive mobile overlay menu.
- **Interactive Command Palette (`Ctrl + K` / `Cmd + K`)**:
  - Real-time command search to jump to sections (`#projects`, `#experience`, `#skills`) or trigger downloads.
- **Skills Category Filter**:
  - Filter between `All Skills`, `Programming & Mobile`, `Databases & Big Data`, `BI & Analytics`, and `Engineering Tools`.
- **Haptic Sound Synthesizer**:
  - Web Audio API zero-dependency micro-audio clicks for buttons, tabs, and navigation links.
- **One-Click Contact Copy**:
  - Quick-copy buttons for phone (`+91 9014467153`) and email (`harshavardhan0764@gmail.com`) with toast notifications.
